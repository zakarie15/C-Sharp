# C# Programming

## Subject Outline

This course introduces the fundamentals of Visual Programming using C# and .NET. Students will learn programming concepts, C# syntax, variables, control structures, methods, arrays, classes, objects, and graphical user interface development.

## Chapters / Topics

1. Introduction to C# and .NET
2. Visual Studio and C# Programming Environment
3. Variables, Constants, and Data Types
4. Operators and Expressions
5. Input and Output
6. Decision-Making Statements
7. Loops and Repetition
8. Methods and Functions
9. Arrays and Collections
10. Classes and Objects
11. Object-Oriented Programming
12. Inheritance and Polymorphism
13. Exception Handling
14. Windows Forms and GUI Programming
15. Events and Event Handling
16. File Handling
17. Building C# Applications

## Course Objectives

By the end of this course, students should be able to:

* Understand the fundamentals of C# and .NET programming.
* Write, compile, run, and debug C# programs.
* Use variables, data types, operators, and control structures.
* Create and use methods, arrays, and collections.
* Understand classes, objects, and basic object-oriented programming.
* Apply inheritance and polymorphism in C# programs.
* Handle errors and exceptions effectively.
* Create graphical user interfaces using C# and Windows Forms.
* Develop simple functional applications using C#.
